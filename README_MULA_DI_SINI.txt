FABA FACE YOUR FUTURE - PANDUAN RINGKAS

1. Extract ZIP ini ke satu folder di laptop Windows.
2. Pastikan Python dipasang (python.org) dan tersedia dalam PATH.
3. Double-click START_FABA_APP.bat.
4. Chrome/Edge akan buka http://localhost:8000.
5. Klik Start Camera dan benarkan akses kamera.
6. Klik Let's Play, pilih THIS atau THAT sebanyak 2 kali.
7. Klik Save Card as PNG untuk simpan kad digital.

NOTA:
- Percuma, tiada login, tiada AI, tiada database, tiada upload selfie.
- Jangan tutup tetingkap command prompt semasa app digunakan.
- Nama program dalam bahagian Explore FABA adalah placeholder.
- Untuk tambah program sebenar, buka index.html dalam Notepad dan ubah senarai PROGRAMMES serta URL brosur.
- Kamera memerlukan localhost atau HTTPS; jangan buka index.html melalui file:// jika kamera tidak berfungsi.
- Kad PNG disimpan ke folder Downloads pengguna.
- Keputusan identiti berdasarkan pilihan kedua; ini demo santai, bukan ujian psikometrik.
- App ini tidak secara automatik menghasilkan pautan peribadi yang boleh dibuka semula pada telefon.
